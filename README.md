# Магазин электроники — вариант 27

WinForms, .NET 8, Entity Framework Core 8 и PostgreSQL. Откройте `WinFormsApp1/ElectronicsStore.sln` в Visual Studio 2022 с рабочей нагрузкой «Разработка классических приложений .NET».

## ЛР2 — PostgreSQL, миграции и журнал

1. В PostgreSQL (например, через pgAdmin) создайте отдельную БД `electronics_store` и пользователя с правами владельца этой БД. Не используйте общую или производственную базу.
2. Задайте пользовательскую переменную окружения `ELECTRONICS_STORE_CONNECTION`: `Host=localhost;Port=5432;Database=electronics_store;Username=ваш_пользователь;Password=ваш_пароль`. Пароль хранится локально, в Git его не добавляйте. После изменения переменной перезапустите Visual Studio.
3. В Visual Studio восстановите NuGet-пакеты и запустите проект (`F5`). Приложение применяет миграцию `InitialCreate` при старте. Можно применить её заранее в консоли диспетчера пакетов: `Update-Database -Context DataContext` (проект `ElectronicsStore` выбран как стартовый и как проект по умолчанию).
4. В меню «Справочники» добавьте товар и клиента, в меню «Операции → Заказы» оформите заказ. При оформлении остаток уменьшается в той же транзакции, что и добавление заказа с позициями. Статусы меняются последовательно: «В обработке» → «Отправлен» → «Доставлен». Справочники удаляются логически: позиции и данные прошлых заказов сохраняются.
5. Журнал Serilog: `%LOCALAPPDATA%\ElectronicsStore\Logs\store-YYYYMMDD.log`. При проверке в pgAdmin должны быть видны `Products`, `Customers`, `Orders`, `OrderItems` и `__EFMigrationsHistory` в схеме `public`.

Цена, название модели, категория и имя клиента записываются в заказ на момент оформления. Редактирование справочников не меняет эти данные задним числом.
